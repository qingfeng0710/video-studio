# Video Studio

## 0. 最高优先级

制作目标不是“导出一个 MP4”就算完成，而是做出观众能轻松阅读、与讲解同步、视觉风格贴近用户参考模板的成片。

优先级从高到低：
1. 用户本轮明确要求；
2. 用户提供的参考视频、图片、品牌规范和素材；
3. 本 Skill 的强制规范；
4. 本 Skill 的默认参数。

**核心视觉要求：文字必须慢速、按语义顺序逐句/逐行依次出现；新文字出现时，之前已出现的文字继续留在画面上。** 后文在轮到它之前必须完全隐藏。不得将整页文字一次性显示，也不得做成上一句消失、下一句替换的字幕轮播。

## 1. 默认输出与制作边界

- 默认画幅：16:9，1920×1080，30 fps。
- 默认交付：MP4，H.264（libx264），yuv420p；有音频时使用 AAC、48 kHz，并启用 `+faststart`。
- 默认离线制作：本地 Python 与 FFmpeg；可使用 Pillow 绘制文字层/逐帧画面，必要时使用 NumPy。
- **不调用视频生成模型、云端视频生成或在线渲染服务**，除非用户明确改变授权。
- 开始前检查 Python、FFmpeg、FFprobe、中文字体和输出目录可用性。缺少依赖时先说明；未经允许不联网安装、不修改系统配置。
- 真实软件画面优先采用用户提供的截图/录屏或可验证素材。人工绘制的 UI 必须标注“示意界面”，不得冒充真实软件录屏。
- 不得编造 Star 数、下载量、许可证、功能、性能、数据规模或来源。无法核实时省略或标注待核实。

## 2. 强制文字动画规范

### 2.1 出现顺序与保留规则

1. 先将口播拆成有语义的短句或短行，按实际讲解顺序编号。
2. 初始时，所有尚未轮到的文字图层必须完全隐藏（透明度为 0，或不在可见区间）。
3. 每组文字独立成层，拥有独立的开始时间、淡入时长、位置和可见区间；不得把整段文字预先烘焙进同一张背景图。
4. 第 1 组出现后保持可见；第 2 组出现时，第 1 组继续显示；第 3 组出现时，前两组继续显示，以此类推。
5. 新文字不得导致旧文字跳位、缩小、消失或重新排版。若需要调整布局，必须在该场景文字出现前完成布局设计。
6. 只有在进入一个新的语义场景/新页面时，才可以按分镜清屏或重置文字；必须有明确的场景切换理由，不能为了塞入更多文字而随意清除旧内容。
7. 重点词可使用绿色或参考模板中的强调色，但仍按口播顺序出现，不能提前泄露后文。
8. 不得使用整页淡入、整块文字同时出现、快速打字机、逐字飞入、弹跳、闪烁或夸张缩放代替逐句出现。

### 2.2 慢速节奏（默认强制值）

- 每组文字淡入：**0.8–1.0 秒**。默认使用 0.9 秒；除非用户明确要求，不得低于 0.8 秒。
- 每组文字完全出现后，基础阅读停留：**至少 2.0 秒**，之后才允许开始下一组。
- 较长内容按字数延长阅读时间：中文可按约 3–4 字/秒粗估；实际采用 `max(2.0 秒, 中文字符数 ÷ 3.5)` 作为基础阅读时长，再结合术语难度、行数和画面复杂度增加时间。该估算是下限参考，不是要求观众必须按此速度阅读。
- 一行短句通常从开始淡入到下一组开始出现，不少于约 2.9 秒；两行或较长句通常不少于约 3.5 秒。内容复杂时继续延长。
- 两组之间允许 0.2–0.5 秒自然间隔；不得为了追赶总时长而压缩上述淡入和阅读停留。
- 动画以柔和淡入为主，可搭配轻微上移（建议 8–20 px）；不要有明显弹跳、突然位移或过强运动。
- 文字入场与对应口播同步或略晚，不得明显提前。若口播更慢，按口播节奏延长；不能让文字先于讲解很久出现。
- 若用户没有给旁白，按可读性安排节奏，并在交付说明中说明这是无旁白节奏版本。
- **宁可延长视频，也不能让文字闪得太快。**

### 2.3 时间轴示例

以下仅展示“累计保留”逻辑，实际时间按文案长度和口播调整：

| 时间 | 应显示内容 |
|---|---|
| 0.0–0.9 秒 | 第一句从隐藏缓慢淡入 |
| 0.9–2.9 秒 | 第一句完整保留，供阅读 |
| 2.9–3.8 秒 | 第二句淡入；第一句继续显示 |
| 3.8 秒以后 | 第一、二句同时保留，直到下一组按节奏出现 |
| 后续 | 第三句、第四句依次加入；之前文字持续可见 |

时间轴必须明确写出每组的 `start`、`fade_duration`、`hold_until` 和 `voiceover_cue`（如有）。不能只写“依次出现”而不给时间参数。

## 3. 排版与场景容量

- 用户参考模板优先。默认可采用深色背景、白色主文字、绿色重点词、左侧文字与右侧真实界面/功能卡片，但不得覆盖用户的参考风格。
- 留白充足，字号层级清晰，文字不贴边、不遮挡主体；中文字体必须实际检查，禁止方框字、缺字和意外换行。
- 在分镜阶段预留后续文字加入后的空间，不能只按第一句话设计画面。
- 每个场景应设置合理的文字容量。若继续累计会导致拥挤：在完整语义段落结束处切换新场景/新页，并在切换时有意识地重置内容；不得在同一场景中途随意清掉前文。
- 不得为容纳更多文字而不断缩小字号。优先精简分组、调整版式或增加场景时长/场景数量。
- 动画保持克制：淡入、轻微上移、缓慢平移/缩放即可；不使用无必要的粒子、炫光和花哨转场。

## 4. 标准制作流程

### 步骤 1：检查输入与环境

读取用户文案、旁白、参考视频/图片、素材和输出要求。检查 Python、FFmpeg、FFprobe、Pillow（如使用）和中文字体。确认输出目录可写。缺少非关键资料时采用默认值；只有会导致成片方向错误的关键信息缺失时，才向用户问一个最必要的问题。

### 步骤 2：分析参考样式

分析画幅、背景、配色、字体层级、文字位置、图文比例、素材真实性、动画方式、转场和节奏。不能只模仿颜色而忽略文字出现方式。若参考视频有明确逐句出现节奏，优先复刻其节奏与布局。

### 步骤 3：拆分文案与分镜

按口播顺序拆分语义短句，不要机械地每个标点切一行。每组至少记录：
- 组号与文字内容；
- 所属场景；
- 入场开始时间；
- 淡入时长（默认 0.9 秒）；
- 完全出现后的阅读停留时长；
- 保留结束时间；
- 对应旁白时间点/语句（如有）；
- 强调词样式与素材来源。

先确定完整场景布局，再安排各文字组入场。分镜必须能回答：任意一个时间点，哪些文字可见、哪些文字仍隐藏。

### 步骤 4：实现动画

- 使用独立文字图层/对象；每层具有独立时间控制。
- 对于开始时间为 `t0`、淡入时长为 `d` 的文字层，在 `t < t0` 时完全隐藏；在 `t0 ≤ t < t0+d` 时平滑增加透明度；淡入完成后透明度保持 100%，直到场景结束或分镜明确指定的移除时间。
- 透明度可使用线性或平滑缓动曲线；不得使用会突然跳变的关键帧。
- 前面文字的可见区间必须覆盖后续文字的入场时间及其后的阅读区间。
- 逐帧绘制时，应按目标帧率计算时间与帧号，避免浮点累计误差；使用 FFmpeg 滤镜时，逐层检查 `enable`/时间表达式与 alpha 逻辑。
- 生成后续画面时，必须继续合成所有仍处于可见区间的旧文字层，不能只绘制当前新句子。

### 步骤 5：合成与音画同步

使用 FFmpeg 将画面序列与音频合成为 MP4。保持音频起点、帧率和画面时间基准一致；不拉伸或裁切旁白来迁就动画。若视频时长不足以容纳阅读停留，应延长画面或调整分镜，不得加速文字。没有音频时不要伪造旁白。

### 步骤 6：质量检查

先用 FFprobe 检查容器、视频编码、分辨率、帧率、时长、像素格式和音轨。再按每组文字抽帧检查至少三个时点：
1. 入场前：该组文字完全不可见；
2. 淡入中：该组文字平滑出现，无突跳；
3. 完全出现后及下一组入场时：该组清晰可读，之前文字仍然保留。

另外检查场景切换、首尾帧、中文字体、错字、遮挡、黑帧、缺帧、意外闪烁和音画同步。抽帧不仅要看单帧，还要连续播放检查节奏是否过快。任何一项不通过，修正并重新渲染、复检。

### 步骤 7：交付

只有文件真实生成且通过检查后，才可称为完成并提供下载链接。说明格式、分辨率、时长，以及尚未验证的事项。不得把脚本成功、命令执行结束或文件存在等同于成片合格。

## 5. 强制验收清单

交付前逐项确认：

- [ ] MP4 可正常播放，画幅、分辨率、帧率符合要求。
- [ ] 所有后续文字在轮到之前完全隐藏。
- [ ] 文字按语义/口播顺序逐句或逐行出现，不是整页同时出现。
- [ ] 默认淡入不短于 0.8 秒，完全出现后至少留 2 秒阅读时间；长句已适当延长。
- [ ] 新文字出现时，前面已出现的文字仍在原位持续保留。
- [ ] 没有快速打字机、闪烁、突然弹出或无故跳位。
- [ ] 文字与旁白同步或略晚，没有明显提前展示后文。
- [ ] 累计文字不会挤压画面；需要重置时只在明确的新场景/新页面进行。
- [ ] 中文字体、换行、字号、对齐和颜色正常，无错字、缺字或遮挡。
- [ ] 已抽查每组文字入场前、淡入中、入场后，以及下一组入场时的连续画面。
- [ ] 无明显黑帧、缺帧、意外闪烁或音画不同步。
- [ ] 已实际播放检查节奏，而非只依赖脚本或 FFprobe。

任何一项未通过，不得交付为最终成片。

## 6. 故障处理

- **文字出现太快**：先将淡入调至 1 秒，再增加阅读停留；必要时延长视频。不得缩短到最低值以下。
- **后续文字提前出现**：检查其开始时间、图层 alpha 和可见区间，确保入场前完全隐藏；重新抽帧。
- **旧文字消失**：检查合成逻辑，确保每帧继续绘制所有仍可见的文字层；重新渲染。
- **文字跳位/缩放**：固定旧文字层的位置、字号和尺寸；在场景开始前完成布局。
- **画面拥挤**：在语义段落边界切换新场景；不要随意清除同一场景的旧文字，也不要无限缩小字号。
- **中文字体缺失**：选择本机可用的中文字体并实际检查字形；不得交付方框字。
- **音画不同步**：检查音频起点、帧率、时间基准和合成参数后重新导出。
- **渲染失败**：保留错误日志，定位失败步骤后重试；不得将未完成文件伪装成成品。
- **环境缺失**：向用户说明缺失项和可行的本地处理方式；未经授权不联网安装、不调用云端替代方案。

## 7. 与用户协作

- 用户本轮明确要求优先于本 Skill 默认值。
- 用户要求先看短样片时，先制作约定时长的样片并等待反馈，不要擅自继续制作整段视频。
- 用户确认样片效果后，再按确认的视觉规范制作完整视频。
- 用户要求“不调用视频模型”时，严格使用本地程序与 FFmpeg；不得暗中改用在线服务。
- 不要声称正在后台持续制作；只有实际生成并验证的文件才能作为交付物。
